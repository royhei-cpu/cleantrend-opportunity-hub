Exact score definition

Opportunity score = Momentum 0–25 + Differentiation 0–20 + Value 0–20 + Repeat 0–15 + Execution 0–20. The total ranks merchant potential; it does not by itself make an item Priority.

  1. 90–100Leading evidence
  2. 78–89Priority-eligible score
  3. 70–77Strong Watch range
  4. <70Early evidence

Exact Priority Test rule: all five gates must pass—external product, nonviral lane, score 78+, demand proof, and no close equivalent in the 103-item Target catalog captured here. “No close equivalent” means no Target item in the same canonical category shares the product’s core format, such as tablet, refill, powered brush, mop or foam. This is a screening rule, not a claim about every live Target.com SKU. 310 external items have a captured Target gap; 117 now pass all five gates.

How to read the data

Directional evidence, clearly labeled.

01Published demand

Retailer-provided “bought” or bestseller indicators. Useful, but not audited unit sales.

02Verified sold count

A sold count displayed by the marketplace at the time this snapshot was captured.

03Review proxy

Rating volume used as a directional indicator of cumulative demand and product maturity.

04Scout signal + score

Assortment observations have no implied sales. Scores blend momentum, differentiation, value, repeat potential and feasibility.
