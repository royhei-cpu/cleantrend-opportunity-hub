# White Label Workshop

Thirty-six A0 exterior design proposals cover the original twenty-seven Homecare Atlas subcategories. The default opens on laundry; the workshop includes laundry handling, storage, pantry organization, waste/recycling and odor control alongside the original care tools and formulas. Apparel, toys, consumer electronics, bedding and general home-repair tools are outside scope. The public name is **White Label Workshop**, per the user's correction. These are dimensioned design studies with engineering allowances, not production CAD, approved formulas, supplier quotes or verified Target gaps.

The website adds two recommended national-brand references per proposal, sourced manufacturer facts and displayed prices where successfully read, suggested changes, validation plans, four color references, an editable BOM and a transparent cost model. Unknown duty stays blank; prices in different currencies are never converted or used to claim a percentage saving. Original catalog records, dates, Target verification and saved checkout records remain unchanged.

The default A0 archive is Sage. Website color selections recolor the actual Blender-exported geometry when interactive 3D is enabled. Other studio renders retain their explicitly labeled Sage finish. A configured HTML brief and CSV capture changed color/cost assumptions; changes are not automatically persisted across concept or workspace changes. The downloadable base archive is labeled separately from configured exports.

## Reproduce

1. Run `python3 workshop/build_data.py` from the repository root to reproduce authored proposal data. This preserves the authored November 4 date; it does not perform research or refresh source evidence.
2. Run `blender -b --python workshop/blender_workshop.py -- --data source/workshop-data.json --out assets/workshop`. Blender 5.2.2 LTS was used. Each native scene contains editable materials, cameras, lights and exterior part groups. Geometry uses metres; public specifications use millimetres. `--ids compact,refill` restricts work; `--samples 32` controls studio quality.
3. Run `node workshop/package_packs.mjs` and `python3 workshop/archive_packs.py` from the repository root. The latter checks dimensions, part identifiers, ZIP CRCs and 252 artifact hashes before writing `source/workshop-assets.json`. Temporary offline files are ignored under `workshop/generated/`.
4. Run the source test/build scripts. The site loads its workshop UI and Three.js viewer in separate hashed chunks. Publish source plus all manifest-listed assets; CI creates the runtime chunks.

Each ZIP has 11 files: a Blender scene, GLB, studio image, front image, dimension SVG, geometry metadata, single-concept source data, BOM CSV, offline specification HTML, readme and reproducible Blender script. No external texture or model downloads are required to open the scene. GLB lighting/textures differ from the native Cycles studio. The exploded arrangement is for design review and is not an assembly instruction.

## Verification and design ledger

The initial visual reference was generated with the built-in image tool at `workshop/design-reference.jpg`. Its prompt called for the existing ivory/forest/sage/copper palette, editorial headings, a two-column concept area, national-brand references and four detail tabs. It is a layout study, not a source of product facts. Actual published product studies were modeled and rendered in Blender, not inferred from that image.

- Copy: changed the reference's “Private-label workshop” to the user's exact **White Label Workshop**. All thirty-six concepts have a direct design/cost entry. Manufacturer names, SKU facts and prices come from the research data, replacing illustrative reference text.
- Layout: preserved the site's established header and three primary routes. Added a fourth workspace tab; mobile shows all four in a wrapping grid. The workshop uses the reference's concept selector, two-column model/summary, benchmark band and four detail tabs. CSS and component structure were checked; browser pixels remain unverified. The expanded category and concept flows pass component interaction checks.
- Typography and palette: preserved Georgia headings, Arial controls, ivory `#f7f5ef`, forest `#153f34`, sage and copper. Control font sizes, table scroll containers and mobile input sizes are explicit. Pixel-level typography and viewport checks remain unverified.
- Assets: inspected all thirty-six Blender studio renders in a contact sheet and inspected full-size examples. Fixed the initial camera clipping, visible floor boundary, and overlapping caddy faces. Checked actual GLB dimensions and reversible color/explode operations for every model. Front references use camera-projected dimension anchors, label the unseen depth, and say they are not manufacturing drawings.
- Spacing and controls: separated the visual concept, recommended benchmarks and technical detail. Tests exercise concept/deep-link selection, unit conversion, palette state, cost edits, validation, item identity and file integrity. Keyboard tab handling and 44px action targets follow the existing interface.
- Intentional deviations: the existing header stays ivory; new literal naming follows the user; source-driven benchmark content replaces invented reference comparisons; default renders are honest A0 exterior design studies. Production engineering, chemical formulas and commercial validation remain open.
- Browser limitation: the in-app browser's admin security-policy verification blocked preview in the preceding site repair and again for this workshop expansion. No alternative route may bypass that restriction. Automated component/geometry checks and Blender render inspection do not establish visual browser or device QA, native viewport fidelity or a 10/10 screenshot match.

## Home-care expansion

`workshop/homecare-expansion.json` adds twenty-four proposals and thirty-nine source references, bringing the library to thirty-six proposals and fifty references. `build_data.py` asserts that workshop categories exactly match the existing twenty-seven catalog categories. Every category has an actual model, specification, BOM, cost scenario and downloadable pack. The new subcategory selector filters product choices and shows counts; the default is the laundry sorter, and old concept links still resolve. The four shortcuts highlight Laundry Care, Trash Bags & Waste, Odor Control and Cleaning Accessories.

Manufacturer product pages, category entries, support records and indexed-only references are identified individually. Their source depth differs; exact-SKU purchase, current pricing, physical measurements and Target assortment checks remain validation gates. One Drillbrush comparison reuses the existing manufacturer-linked catalog record and is explicitly marked as not live-rereviewed. No original catalog freshness dates are advanced.

New native Blender studies cover garment bags, a hamper, a drying rack, storage boxes, dividers, a vanity organizer, canisters, recycling and food-waste bins, sponges, dusting, toilet/sweep/glass tools, formula packaging, a nonfunctional hand vacuum, drill attachments, an odor pod, auto care, mechanical drain capture, household gloves and outdoor brushes. Textiles, dipped rubber and wire frames use specific construction targets instead of the former universal molded-wall line. Electrical and disinfectant studies remain nonfunctional exterior proposals; their BOM allowances are not supplier approvals or certified engineering.
